Kryptos

Jim Sanborn's 1990 sculpture at CIA Headquarters, Langley, Virginia, placed on the real campus footprint. Walk from the Morse code stones at the New Headquarters Building entrance into the courtyard, read the copper, and set the sun to any date and time.
